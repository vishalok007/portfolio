## 🚀 Overview

This repository contains the personal portfolio and interactive AI engineering showroom of **Vishal Kumar**, an AI Engineer and Data Science specialist.

Built with modern Silicon Valley dark tech styling, bento-grid layouts, and **live interactive machine learning simulators** that demonstrate practical ML fundamentals directly in the browser.

---

## ⚡ Key Interactive Features

1. **Interactive ML Benchmark Explorer (`MLExplorer.tsx`):**
   - Interactive decision threshold tuning slider (0.05 to 0.95).
   - Dynamic real-time calculation of **Precision**, **Recall**, **F1-Score**, and **Accuracy**.
   - Dynamic Confusion Matrix tracking **True Positives (TP)**, **False Positives (FP)**, **False Negatives (FN)**, and **True Negatives (TN)** dynamically.
   - Inference latency and hardware specs comparison across CPU and GPU.

2. **Interactive AI Sandbox Simulator (`AIPlayground.tsx`):**
   - **RAG Vector Search:** Simulates dense vector embedding retrieval (FAISS Cosine similarity) combined with synthesized LLM response generation.
   - **BERT Sentiment Analysis:** Fine-tuned transformer sentiment classification with confidence scores.
   - **Prompt Optimizer:** Generates production-grade structured system prompts.

3. **Global AI Assistant Widget (`AIChatAssistant.tsx`):**
   - Conversational AI assistant trained on verified credentials, projects, and tech stack facts.
   - Hybrid architecture: calls Gemini API when key is available, with instant zero-latency local knowledge-base fallback.

4. **Studio Voice Greeting Pitch (`AudioGreeting.tsx`):**
   - Web Speech API integration with priority sorting for natural neural human voices to deliver a 20-second audio elevator pitch.

5. **Dual-Mode Resume Modal (`ResumeModal.tsx`):**
   - Switch between an **Interactive Visual View** and a clean **Digital A4 Document View**.
   - Direct Print-to-PDF (`window.print()`) and plain text CV export.

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation
```bash
# Clone repository
git clone https://github.com/vishalok007/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build & Lint
```bash
# Type check & build for production
npm run build

# Run Oxlint
npm run lint

# Preview production build locally
npm run preview
```
